# 三台 OpenMV 脚本

最终编号：红圆 1、黄色三角形 2、蓝色正方形 3。对应脚本 `openmv_red_circle.py`、`openmv_yellow_triangle.py`、`openmv_blue_square.py`，每份可单独保存为对应相机的 main.py；黄/蓝脚本已内嵌几何函数，无需另复制模块。UART3/P4 TX，115200 8N1，160×120 原生方向。具体线路见[接线表](../../../../board/skystar_f407/three_gimbal_wiring.md)。

红色脚本沿用颜色块基线，不含独立圆形分类器；不能把文件名当作圆形判别已验证。黄/蓝通过凸包简化、顶点、面积及方形边角检查筛选实心完整几何图案，采用三帧稳定门限和歧义拒绝。颜色阈值、强透视/遮挡适应性以及两只新相机帧率均未现场验收。

红1曾经由 IDE 工具菜单保存为 main.py，并核对归一化文本一致；黄2、蓝3的烧录状态来自用户报告，本轮没有独立读取其板上脚本。部署时应明确相机身份，在 IDE 使用“将打开的脚本保存到 OpenMV Cam（作为main.py）”；本次 Git 提交没有重新写任何相机。

历史离线几何测试为10项；测试里的身份期望仅随用户最终编号修正为黄2/蓝3，几何接受条件没有放宽。当前天空星静止常亮版关闭三个相机接收器，不代表这些脚本已经形成三路跟踪闭环。
