# 独立临时输入格式 stm32-p0/v1

本格式只供 `ikkkkk19` 的 STM32 软件 P0 测试使用，不是团队冻结协议。
不改变现有 FPGA RTL、RGB565 或 UDP。历史 OpenMV 八字节脚本不兼容本版本；
当前输入来自本地夹具，不声称 FPGA、OpenMV 或最终固定相机已接入。

## 二进制帧

UART 编译配置为 115200、8N1；逐字节输入，固定 26 字节，无转义。
所有多字节字段小端；偏差为有符号二补码 int16。

| 字节 | 字段 | 临时规则 |
|---|---|---|
| 0–1 | magic | `AA 55` |
| 2 | version | 1 |
| 3 | total_length | 26，其他值拒绝 |
| 4 | valid | 0 或 1，其他位/值拒绝 |
| 5 | config | 1，未实现配置切换，其他配置拒绝且不推进帧水位 |
| 6–9 | session | uint32，非零 |
| 10–13 | frame | uint32，本临时版本允许首帧为 0 |
| 14–17 | source_ms | uint32，仅保留供诊断，不作为新鲜度时钟 |
| 18–19 | dx | 模拟像素误差，闭区间 [-80,80] |
| 20–21 | dy | 模拟像素误差，闭区间 [-60,60] |
| 22–23 | crc16 | 对字节 2–21；CRC-16/CCITT-FALSE：poly=0x1021、init=0xFFFF、无反射、xorout=0 |
| 24–25 | tail | `0D 0A` |

`valid=1, dx=dy=0` 是有效零误差；`valid=0` 时 dx/dy 必须为 0。
本尺寸和误差范围是独立模拟约定，不是 OV5640 的图像/闭环接口定义。
输入构造使用 Python `struct.pack` 和标准库 `binascii.crc_hqx`，不调用被测 C CRC。

## 接收、序号和恢复

- `received_ms` 是 MCU RX ISR 的本地 uint32 毫秒 tick，完整帧取最后字节时间。
  host 夹具显式注入这个时钟；source 时间只能作为日志字段。
- 相邻字节间隔达到 20 ms 或未完成帧空闲达到 20 ms，丢弃部分帧并记录 `partial`。
  CRC/尾部/字段错误后逐字节滑动重同步，保留失败候选中的可能新帧头。
- 首个合法 session 建立水位；同 session 的 frame 必须严格增加。
  更大的 session 允许从任意 frame 重新开始并清控制历史；较小 session 拒绝。
  session 和 frame 不支持回绕；frame 耗尽须用更大的 session，session 耗尽须明确重启。
- 距上个被接受完整帧达到 200 ms 进入 `timeout`。边界为 `>=200`，200 ms 未经最终标定。
  接受输入前也检查断流，避免主循环未显式 tick 时继承历史。
- 排队输入在处理时已达到 200 ms 则拒绝为 `stale`。
  `auto` 或 PID 参数变化后，切换之前接收的帧也拒绝；切换同一毫秒的更高序号可接受。
  时间差使用 uint32 回绕减法；模式屏障只比较短时间内的有符号差。
- 无目标、超时、帧拒绝清测量、PID 积分/历史、滤波和跳变基准。
  保留已接受 session/frame 水位，断流不能让重复/旧会话复活。
- 恢复首帧用当前输入初始化滤波/跳变与微分历史，dt 初值 10 ms。
  自动模式只有新鲜有效帧才重新启用自动计算；手动模式继续消费输入但不运行 PID。

## 软件状态、输出与参数

观测状态为 `waiting / tracking / no_target / timeout / rejected`，模式独立为 `auto / manual`。
状态分别上报 `VALID`、`ENABLED`、拒绝原因、session/frame、源与接收时间。
失效策略是**禁用自动更新并保持最后软件应用脉宽**，不是物理停机。
固件驱动仍可能维持 PWM；PWM、电机停转、限位及失联停止均须另行台架验证。
`REQ_PAN/REQ_TLT` 是限幅和步长限制后的拟应用值；`PAN/TLT` 是软件应用缓存，
并非传感器实测位置。host 检查它们一致，不证明 PWM 波形或舵机位置。

为对照旧算法，模拟默认 Pan Kp/Ki/Kd=3/0.5/0，Tilt=5/0.8/0；
Pan home=1450 us，Tilt home=1500 us；Pan范围600–2400，Tilt范围1000–2400 us。
模拟正 dx 增加 Pan，正 dy 减少 Tilt。滤波系数0.35/0.20，跳变上限40 px/帧，
每轴死区闭区间[-3,3]，10 ms基准脉宽步长60 us、单次上限350 us。
这些仅为继承原型的模拟参数；相机固定的 OV5640 最终坐标、符号、PID、
机械范围及使能条件待重新标定，不是像素到角度的标定变换。

## 临时文本命令

USART3 的 ASCII 命令以 CR/LF 结束，最长63字节，超长整行丢弃到行尾。
中断只排队，命令解析与 PID/应用值更新都在主循环完成。

- `pan N`、`tlt N`：只改变对应轴，另一轴来自当前应用值；N为整数，必须在各轴范围内。
- `auto`：清控制历史和旧观测，等待新帧；不立即应用旧自动测量。
- `pkp/pki/pkd/tkp/tki/tkd V`：有限十进制非负数，范围[0,50]，保留当前模式、清历史并等待新帧。
- `st`：请求状态。`auto/st` 不允许额外字段，数字不允许尾随垃圾、指数、NaN/Inf。
- 错误命令记录 `command`，不改变轴值、模式或 PID 参数；下一完整正确命令可恢复。

RX队列容量127字节，队列/硬件接收错误使当前队列作废并记录 `overflow`。
main消费队列时短暂屏蔽中断并恢复原 PRIMASK，避免 ISR 与消费共同修改快照。
