# 三套云台、OpenMV 和激光：本轮最终接线

更新：2026-11-04（北京时间）。以用户最后确认的 **1 号红圆、2 号黄色三角形、3 号蓝色正方形** 为准。早期“蓝 2 / 黄 3”的编号和 2026-10-27 两套接线图不再适用于本轮。引脚丝印 `A03/A3`、`C07/C7`、`D02/D2`、`E02/E2` 等分别指同一个 MCU GPIO。

## 三套信号总表

| 编号与纸靶 | OpenMV P4/TX → 天空星 RX | 天空星接收外设 | 水平 PAN 信号 | 俯仰 TILT 信号 | 激光模块控制/PWM 端 |
|---|---|---|---|---|---|
| 1：红色圆形 | A03 / PA3 | USART2_RX，AF7 | D12 / PD12，TIM4_CH1，AF2 | D13 / PD13，TIM4_CH2，AF2 | E02 / PE2 |
| 2：黄色三角形 | C07 / PC7 | USART6_RX，AF8 | E09 / PE9，TIM1_CH1，AF1 | E11 / PE11，TIM1_CH2，AF1 | E03 / PE3 |
| 3：蓝色正方形 | D02 / PD2 | UART5_RX，AF8 | D14 / PD14，TIM4_CH3，AF2 | D15 / PD15，TIM4_CH4，AF2 | B00 / PB0 |

表中 PWM 是计划用于对应轴的信号引脚和外设映射，不表示本轮三套舵机已完成运动验收。水平控制模型沿用 270°位置型、俯仰沿用 180°位置型；安装零位、方向和机械限位仍需逐套标定。

## 每只 OpenMV

- 相机端使用 **UART3、P4/TX、115200 8N1**；P4 分别接表中各自的天空星 RX，三只 TX 不并接。
- 每只 OpenMV 的 GND 接天空星 GND，外部电源模块的地也接入同一信号参考地。
- 帧格式沿用 `AA FF dx_le16 dy_le16 valid EE`，共 8 字节。帧内没有设备编号；1/2/3 号身份由接收端口绑定，不能只改显示名称而交换接收口。
- 红 1 的 `main.py` 曾通过 IDE“将打开的脚本保存到 OpenMV Cam”保存；黄 2、蓝 3 的程序已写入由用户报告，本次常亮测试未重新连接并逐只回读验证。

## FPGA ↔ 天空星

| 发送端 | 接收端 | 用途 |
|---|---|---|
| FPGA J23 TXD（既有约束 AB25） | 天空星 PC11 / USART3_RX，AF7 | 控制命令、心跳及已有测量协议 |
| 天空星 PC10 / USART3_TX，AF7 | FPGA J23 RXD（既有约束 AB26） | 状态与命令回执 |
| FPGA GND | 天空星 GND | 共地 |

此链路为 **USART3、115200 8N1**。AB25/AB26 来自[已有约束](zynq_uart_bridge_v12.xdc)及[控制协议](../../docs/zynq_skystar_motion_protocol_v1.md)，不是新测量的连接器针序或电压结果。相机的 UART3 名称属于 OpenMV；它与天空星的 USART3 是不同设备上的外设。

PC10、PC11、PD2 已用于本轮串口；不要同时启用占用这些脚的 TF/SDIO 功能。2026-10-27 旧文档的 USART1/H1 调试日志连接不是当前 FPGA 控制口。

## 激光和舵机供电

- PE2、PE3、PB0 分别接各模块的**控制/PWM 输入端**，不是模块电源正极。模块供电继续使用各自符合额定参数的原配/外部供电，模块 GND 与天空星共地。
- 当前测试软件将三路按高电平有效控制，使用 GPIO 持续高电平，未生成调光 PWM。用户已确认第三套接线修复后高电平亮、低电平灭，之后确认三支均常亮。
- 舵机信号线按总表接 PAN/TILT；正负供电来自符合对应舵机额定参数的动力电源。动力电源负极、舵机信号地与天空星 GND 共地，大电流回路经动力电源返回。
- 本次没有逐套测量供电电压、峰值电流或光功率，接线记录不补填这些参数。

## 本次结束时的实际状态

截至用户确认三灯常亮时：三支激光供电已接回，PE2/PE3/PB0 均持续输出高电平；舵机动力和插头按用户确认保持隔离，六路 PWM 输出为 0。之后保存代码及推送 GitHub 没有发送 STOP，也没有操作板上输出。这个记录是当时状态，不代表下一次启动时自动复现。

板上使用[三路静止常亮专用版本](../../src/prototype/skystar_openmv/profiles/laser123_static/README.md)：**三路 OpenMV 接收器暂时关闭，USART3 控制链路保留**。因此，相机接线保留不等于当前程序正在接收三路相机数据；不能把本轮常亮验收当作三路视觉或六轴跟踪验收。

当前确认的证据是 350 次采样三路门控为高、六路 PWM 为 0、控制串口故障计数为 0，以及用户“三套都常亮”的现场反馈。完整界限见[本轮报告](../../report/experiments/2026-11-04-three-static-lasers.md)。FPGA OV5640 多目标识别、任务分配、云台粗定位与精准跟踪仍待继续联调。
