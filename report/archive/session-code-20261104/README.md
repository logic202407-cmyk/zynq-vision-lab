# 联调辅助代码历史快照

此目录保存联调中产生的辅助脚本和旧 RTL 的文本副本，扩展名统一追加 `.txt`。它们不是当前构建入口，也没有在本轮执行；部分脚本包含烧录、复位或控制动作，旧地址、时序、接线和相机编号不能直接套用到当前设备。

[inventory.json](inventory.json)逐项列出 546 个本地源码/辅助文件的原始 SHA-256、公开位置或排除原因。其中 205 份独有源码保存为文本，335 份映射到已有源码或相同内容的快照；5 份自动生成的 IP 约束、1 份被截断且 UTF-8 无效的相机读取结果不复制。比较重复内容时仅归一化 CRLF/LF，原始文件哈希仍按原字节计算。

覆盖本地 evidence 下各实验目录第一层源码文件，以及最终 control-only 目录的辅助代码。固件 source/User 树另按版本保存于 profiles；不递归复制厂商工程、工具缓存、生成目录或原始照片。设备序列号和用户主目录已作文本替换，修改次数和发布文本哈希记录于清单；因此脱敏文本不保证与原文件逐字节一致。
