# 测试流程交付：模型建议与纠正

范围：将已存在源码和真实离线证据整理为 [Codex runbook](../../docs/codex_test_runbook.md)，没有在本轮执行测试或硬件操作。

1. 仅发布含 R0/验收新命令的文档会引用远端没有的源码。纠正为先列最小相关文件、区分本地证据与已发布版本；相关源码获准发布后再一起交付，不打包所有未提交工作。
2. `unittest discover` 找不到指定测试时可能 `Ran 0 tests / OK`。纠正为检查必需文件与实际测试数，缺文件、skip 和未运行不计通过。
3. `pl_compare` CLI 会真实启动 UDP；离线错误注入改为已有 mock 测试。xsim 退出码也不能独立判 PASS，应核对八个字段及明确 PASS/Fatal。
4. 单次 100 同帧验收可能提前结束，`--seconds 30` 不能当连续 30 秒。连续接收另用 bench_probe，读取 JSON 而非只看退出码。
5. 用户已确认固定 OV5640 接 FPGA、镜头不随云台转。原型指南采用同帧纸靶/指示点观测的规划边界，不套相机随动的图像中心误差逻辑；PS/STM32 最终架构仍未确定，模拟/回放不算最终实物验收。

复核方法：读取脚本参数、测试与历史输出；定向 diff、文件/链接存在性及敏感信息审查。未升级任何硬件结论，未加入驱动、运动或光源实现。
