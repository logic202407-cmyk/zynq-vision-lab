# 同靶核验与 epoch 参考开发修正

- 初次复制现场采集工具时未复制其相对路径 AXF，实际启动失败；补齐精确部署版本依赖后用新标签复测，保留失败。
- sqlite 事务上下文不会自动关闭连接，导致 Windows 测试文件占用。显式关闭连接后原始 15 项测试通过；没有删测试或放宽异常/耗尽断言。
- 首次 85 项全量测试发现文档链接指向尚未创建的报告，补齐实际报告后重跑；先前失败日志保留。
- 双份持久化日志共同回滚的反例能产生相同区间。参考实现始终标记 production_ready=false，RTL 也明确展示复位后供应者旧 grant 可重放；未包装成唯一性证明。
- 纸靶移动窗口没有获得足够坐标变化。一次分析错误地仅检查一个序列变化便计算相关系数，遇常量序列报错；现检查两侧变化并输出 INSUFFICIENT_EXCITATION。单个静态同靶不能得出运动方向。
- 复杂内联 Python 被 PowerShell 引号规则拒绝，改为独立私有脚本；准备 STOP 监测的步骤也不再放在可能失败的分析之后。输入保护拒绝非前台 IDE 操作，待用户切换后才启动采集。
- Vivado 调用超过 300 秒 MCP 等待限制，未重新运行覆盖；查询原会话确认 source 在 368.471 秒退出 0，保留超时与成功完成两个事实。

本轮真实 PWM 全程关闭，全部运动收敛/失联结果来自明确标注的 RTL/真实 C 模型。可靠 NVM、防回滚、机械标定和全路径 QID 接入仍是独立缺口。
