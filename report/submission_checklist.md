# Submission checklist

This checklist is initially incomplete. Verify against the latest official submission rules before packaging.

- [ ] Actual registration and eligible group verified privately.
- [ ] Exact board/device and tool versions declared.
- [ ] Original PL contribution implemented and explained.
- [ ] Source, simulation, build scripts and interfaces reproducible.
- [ ] Actual board output, resource and timing reports collected.
- [ ] Fair performance/reference comparison and interference tests documented.
- [ ] Independent member rebuild and run completed.
- [ ] Representative AI prompts, outputs and corrections recorded.
- [ ] Reusable Skill validated with applicability and limitations.
- [ ] Public repository, license and third-party provenance verified.
- [ ] Report and genuine demonstration video prepared.
- [ ] Required final-stage English one-page poster/template checked.
- [ ] Public materials scrubbed of private information and credentials.
- [ ] Final files, links, commit and checksums checked after upload.

A public repository scaffold alone does not satisfy these deliverables.
