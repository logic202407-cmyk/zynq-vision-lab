# F103 / OpenMV 500mm 红纸靶跟踪板测

日期：2026-11-03。用户授权的独立 F103 + OpenMV 纸靶实验；[应用、工程与复查入口](../../src/prototype/f103_openmv_tracking/README.md)，[对话进度与未完成项](../../src/prototype/f103_openmv_tracking/PROGRESS.md)。

F103 v4 使用 PB0 检测即亮、200ms 失联关断；已纠正的俯仰反馈方向保留。固定约 500mm 距离，通过开/关光画面对照读得原图光点约 `(76,50)`，在 STM32 侧采用期望 `dx=-4,dy=10`。Ki 改为水平 3、俯仰 4，其他整定边界保持。OpenMV R6 阈值 `(0,100,12,41,-3,52)` 未变。

38 项主机 C 断言和 6 项相机兼容检查通过。Keil 编译 0 错误/0 警告，下载 Verify OK，独立 SWD 核对 10032 个程序字节全部匹配，两次完整 Flash 回读相同。35 秒观测收到 1631 帧且没有新解析错误；640 个样本全部有效，619 个位于标定点两轴 ±3px 内。用户确认光点收敛到中心附近。

这些结果不代表动态追踪速度、变距离瞄准或毫米级精度验收。相机盘启动脚本尚未替换，断电自启动未验证；USB-TTL 双向调参、实物断线灭光时序和机械全行程仍待验证。Zynq/FPGA 状态不因本原型上板而升级。
