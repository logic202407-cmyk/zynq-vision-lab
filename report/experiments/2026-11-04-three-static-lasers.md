# 2026-11-04 三路静止常亮测试

本次完成三路固定激光门控的常亮板测：红 1 → PE2，黄 2 → PE3，蓝 3 → PB0。350 次间隔至少 100 ms 的寄存器采样全部为 AUTO，三路门控全部为 1，TIM4/TIM1 CCER 全部为 0，新增控制串口故障计数为 0。用户在接回激光供电后确认“三套都常亮”。采样期间没有发送 STOP；光学连续性是现场确认，未进行示波器占空比或光功率测量。

## 改动和定位过程

早期三路接收诊断固件强制关闭 PE2，PE3/PB0 没有完整的静止测试控制。第三套最初在 PB0 高、低电平下都亮；用户随后确认接线已处理、可正常开关且为高电平点亮。这是现场反馈，不据此推断原始接线问题的具体位置。

保留三路摄像头接收的常亮候选多次进入 SAFE_UART，导致三个门控关闭。后续专用版本关闭本项测试不消费的 OpenMV 接收器，同时保留 USART3 控制链路、STOP、按键及心跳保护，并新增 UART 故障来源、状态及计数。此后板测未再触发该故障。此前故障未定位到具体串口或电气根因，不能声称三路视觉接收问题已经修好。

另一个问题是 AUTO 操作边沿可能在 FPGA 等待上一条回执或处理心跳时丢失，MCU 因此仅停在 ARMED。实际成功启动使用了读回 READY 后立即发出 AUTO 的顺序。FPGA RTL 本轮未因此改动。

专用版本移除了每次循环/心跳中的 `board_outputs(0, ...)` 调用，防止该函数同时清零激光门控而造成点亮间隙。所有舵机输出仍从初始化起禁止；STOP/fault 仍走强制关闭路径。

## 实物与构建证据

- STM32F407 仅更新首个 16 KiB 扇区，更新前完整备份；512 KiB 完整回读与预期一致。
- AC6 6.24 编译，10,836 字节；编译无 C 警告，汇编器仅提示 legacy armasm 已弃用。
- 本地13项寄存器模型检查覆盖各通道组合、无授权不点亮、无效掩码、STOP、按键、失联、串口故障、PWM互锁、摄像头接收隔离。
- 固件和 FPGA 均默认不自动点亮；板测由明确操作建立会话、选择全部通道并使能。
