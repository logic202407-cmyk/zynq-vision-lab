## 通信与图像：已通过和未通过分开

1. COM14 以 115200、8N1 被动接收两轮，每轮 12 秒、10,320 字节、120 行 S1STAT、59 次 SWD 采样。PC 串口发送字节数为 0；实际安全状态保持 STOPPED/BOOT。两轮 SWD 采样都显示 TIM4 CCER=0，三云台软件 PWM 标志均为 0。周期状态不是命令 ACK。
2. 既有固定 OV5640 的 UDP 诊断在 10.047 秒收到 261 个完整帧、0 个不完整帧、2 个异常数据包；261 帧原始 PL 目标有效。有限取图只发送原视频启动/停止数据报，没有运动命令。现场图留私有。
3. 最后画面可见纸上红圆。但原 PL 合并统计的 bbox 延伸到其他红色区域；例如一帧 count=20230、bbox=(5,61,633,403)。这不能证明连通区域隔离、跨相机身份或闭环误差已标定。质量候选的像素数/贴边判定仍有已记录的能力边界。
4. MCU 刚重启，旧测量会话未自动恢复。采样 primary_bound=0、accepted=0，F1 行数为 0，OpenMV 接收帧数为 0。新会话和 OpenMV 反馈的实物复测尚未完成，不能把 UDP 图像接收等同于 MCU 已接受 M2 或产生有效 F1。

## JTAG 故障与执行边界

旧 Vivado 2024.2 会话刷新 VIO 时出现 Xicom 50-38 和 Labtools 27-3176；重新连接和刷新设备后出现 Labtools 27-2312。用户检查并重插 JTAG USB 后，调试服务报告无可用活动目标及可能被其他服务占用。

只重建了本机匹配 2024.2 的 hw_server 连接/服务，没有终止 Vivado 工程、下载位流或改变 FPGA 控制输入。随后按本机 help open_hw_target 的显式对象方式查询，get_hw_targets 数量为 0；保护条件阻止继续选择。保留[实际错误摘录](../evidence/c1-vision-deploy-20261102/jtag-failures.txt)，USB 唯一标识已脱敏。没有用 -quiet 的返回 0 当成调试恢复成功。

因此本轮无法触发 FPGA 状态查询、测量绑定或关联 STOP；没有执行 commit_hw_vio。实际器件中的精确位流版本本轮也未重新核对。原观测候选源码不含 ARM/位置控制入口，但不以此代替本轮失败的调试核读取。

STOPPED/BOOT 与执行 stop 后的 STOPPED/STOP 不同。当前只证明已断动力条件下的新固件启动不授权且寄存器关闭，不能宣称“本轮关联 STOP 通过”，更不能宣称失联时从有输出到关闭的真实波形验收通过。现场只有万用表，PWM 波形仍未测。
