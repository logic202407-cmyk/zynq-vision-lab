# C1 无动力重连复核

用户确认舵机动力与激光供电仍物理断开，天空星与 ST-Link 已通电连接。电脑端换口后，ST-Link 被识别；OpenMV 为 COM12，CH340 本次为 COM15，串口号不作为永久设备身份。没有重复烧录或复位。

通过 SWD 只读完整 512KiB，实际应用 SHA-256 为 `70a3ad2f0117cb9425d47db79eaad32e0c727ed9936665e2b2bef45599e44812`，整片与已批准候选一致；核心运行、状态 STOPPED/BOOT、TIM4 CCER=0。PA0/WKUP 的 500 次离散只读样本均为低，KEY 故障未在这段采样中重现。该结果不能确定此前故障原因，也不能排除采样间的短暂信号。

本机 OpenMV IDE 5.0.0 运行既有 90 秒 RAM 视觉诊断，天空星 OpenMV 接收帧计数读数从 379 增至 1236，软件 PWM=0；当时 `valid=0`，实时画面中可见红圆，但仓库默认 LAB 阈值显示 MISSING。不能把帧接收或画面可见等同于目标识别通过。对照阈值脚本已准备，尚未确认启动或验证效果；不改仓库默认阈值和相机 Flash。

有线网卡为 192.168.1.102/24 且链路 Up；10 秒 UDP 接收 0 个完整帧。Vivado 2024.2 当前枚举 JTAG 目标数为 0，Windows 未枚举到此前的 FTDI JTAG USB 标识。用户确认 Zynq 已通电并重新连接 JTAG USB 后仍相同。Windows 存在一个设备描述符请求失败的 USB 设备、问题代码 43，不能单凭现象认定它就是 JTAG。未下载 FPGA 位流，尚不知当前 FPGA 内具体配置。
