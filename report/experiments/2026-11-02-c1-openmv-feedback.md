# C1 OpenMV 无动力反馈检查

基于 220a57b70596e0766936118effa2949ef5c876be，保持舵机动力和激光物理断开，使用本机 OpenMV IDE 5.0.0 执行 90 秒 RAM 诊断；脚本嵌入仓库红色目标策略，沿用默认 LAB (32,43,13,51,4,52) 和 UART3 115200/8N1，不写相机 Flash、不发运动或光学命令。RAM 脚本指纹及脱敏数据见[实际结果](../evidence/c1-openmv-feedback-20261102/result.json)。

OpenMV 画面实时更新并显示有效目标，但可见检测框只覆盖红圆的一部分，不能把其质心当成已标定的红圆中心。期间 FPGA 通过 VIO 发起查询、观测会话绑定和 STOP；串口回读 S1SYNC、V2A 和 S1ACK 的 CRC 及关联均正确，MCU 接收 FPGA 测量计数最高 71。

35 秒被动接收与 172 次寄存器采样中，PWM 使能保持关闭；天空星 OpenMV 帧计数最高为 0，F1 返回 0 行。只读 PA3 输入抽样 1500 次均为高电平：这不是波形测量，也不能单凭抽样证明断线。需现场核对 OpenMV P4/UART3 TX 到天空星 PA3/USART2_RX，以及共地，再重测。STOP 验证发生于本来已关闭的输出状态，不是带动力失联保护或 PWM 波形验收。

本轮不声称 OpenMV 到 STM32 接收通过，也未验证跨相机目标身份、机械标定或 FPGA 自主运动。现场照片和原始 UART 数据保留在 D 盘，不上传。
