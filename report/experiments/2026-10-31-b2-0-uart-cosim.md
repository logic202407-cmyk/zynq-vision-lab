## Failures retained and corrections

1. Early Tcl sampling exposed an optimized-away observer as X. Enabled debug
   visibility; did not reinterpret X as zero.
2. Tcl socket stepping exceeded the 120-second feasibility target. Batching the
   observation did not resolve transport overhead. Switched to official XSI,
   retaining the real XSim engine and real C parser rather than independent tests.
3. Adding actual MCU boot output caused an early 0.2 ms st trigger to be rejected:
   local ownership requires UART idle. The final test waits 10 ms and confirmed
   ownership before manual stimulus. Exact st/stop expectations remain unchanged.
   Earlier failed runs remain outside Git under evidence/b2-0/run* and xsi2.

## Scope and remaining work

Production RTL and firmware are unchanged. New files are test-only adapter,
testbench, XSI bindings, runner and documentation/evidence. No bitstream, firmware
image, physical serial connection, JTAG or PWM operation was performed.
S1ACK1 remains proposed/approved but not implemented by this checkpoint. Motion
RTL, ACK association, full fault matrix, IRQ race model and PWM shadow model
remain outstanding. Diagnostic LF completion is not command acceptance.
Hardware clock, new XDC control pins, voltage and actual Flash identity remain
unverified. This checkpoint enables continued offline B2 development only.
