# STM32F103C8T6 与 OpenMV 云台控制原型复盘

日期：2026-10-01  
贡献者：`ikkkkk19`  
证据等级：贡献者本人完成的台架原型实测，尚未由其他成员独立复现

## 1. 实验目的

本次实验建立了一套独立于 Zynq 主线的第一版云台控制原型。OpenMV 负责图像识别和目标偏差计算，STM32 负责双轴控制，电脑通过 USB-TTL 查看 STM32 输出的调试状态。

该原型用于提前验证视觉偏差、串口通信、PID 控制和舵机驱动流程，不作为 Zynq PS 应用、PS–PL 联调或最终整机验收结果。

## 2. 实验环境

- OpenMV H7 Plus，RGB565，QQVGA 160×120。
- STM32F103C8T6。
- 本地 STM32 工程使用 STM32F10x 标准外设库 V3.5.0 和 Keil 5。
- OpenMV UART3 TX 连接 STM32 USART1 RX，波特率 115200，双方共地。
- STM32 USART3 通过 USB-TTL 与电脑连接，用于状态查看和手动命令。
- STM32 TIM2 CH1、CH2 分别输出两路舵机 PWM。

本次记录没有冻结舵机具体商品型号、电源实测数据、光照布置、目标运动速度和完整连续运行时长。

## 3. 通信流程

OpenMV 向 STM32 发送 8 字节定长二进制帧：

```text
AA FF dx_lo dx_hi dy_lo dy_hi flag EE
```

其中：

- `dx`、`dy` 为小端序有符号 16 位整数。
- `flag=01` 表示识别到目标。
- `flag=00` 表示目标丢失。

STM32 USART3 通过另一条链路发送 ASCII 文本状态帧。状态字段包含 `DX`、`DY`、Pan/Tilt 舵机脉宽以及两轴 PID 参数。

上述两条串口链路仅属于 STM32/OpenMV 原型，不修改仓库现有的 Zynq 相机数据流、RGB565 定义、PL 结果头或原厂 UDP 传输协议。

## 4. 实测结果

1. OpenMV 运行本次提交的 QQVGA 脚本时，OpenMV IDE 显示帧率约为 46 FPS。
2. 当前 STM32 源码已在 Keil 中完成全量编译，结果为 0 Error、0 Warning。
3. Keil 构建摘要为：Code 9578 B、RO-data 542 B、RW-data 68 B、ZI-data 2748 B。
4. STM32 USART3 状态输出已通过 USB-TTL 实测，上位机能够正常接收包含 `DX`、`DY`、舵机脉宽和 PID 参数的文本状态帧。
5. STM32 与 OpenMV 已用于第一轮视觉跟踪和控制参数调整。

Keil 生成物和临时串口输出只保留在本地，没有复制到公开仓库。本次未保存可随仓库提交的原始串口抓取文件，因此串口结果记录为贡献者本人完成的台架实测，尚不能视为独立复现证据。
