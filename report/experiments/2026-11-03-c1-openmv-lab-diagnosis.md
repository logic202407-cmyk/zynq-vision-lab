# C1 当前场景 OpenMV LAB 对照

在[无动力重连复核](2026-11-03-c1-no-power-reconnect.md)之后，用户启动对照脚本；实际 RAM 测试未修改仓库默认阈值或相机 Flash。默认阈值 `(32,43,13,51,4,52)` 在可见红圆的当前画面中显示 MISSING。对照阈值 `(10,80,20,90,-10,80)` 曾出现 AMBIGUOUS，随后也观察到 MISSING；相应一次 MCU 环形缓冲快照找到 32 帧无效标志。不同时间的光照/曝光不保证相同，不把这些结果当同帧的准确率对比。

按当前 160×120 画面人工选择红圆内部 ROI `(106,18,12,12)`，有限 8 秒 image-only RAM 测试完成；私有画面核对绿框位于红圆内部。三次[LAB 统计的人工摘录](../evidence/c1-openmv-lab-20261103/roi-observation.json)显示 L 范围约 8–15、A 范围约 8–18，部分低于原阈值的 L 下限或对照阈值的 A 下限。这是当前 ROI 的有限样本，不能代表整个红圆、其他曝光或其他靶标。

据此构造仅用于本地 RAM 的暗红候选 `(5,35,8,40,-10,25)`：画面观察到红圆被绿框圈出，同时左边缘有另一块绿框，状态 AMBIGUOUS；一次 MCU 环形缓冲快照中 32 帧均为无效标志。保留单目标歧义保护，不把最大色块默认为目标。候选脚本的 SHA-256 为 `e2ac7966fa3513e4554e2e05ac762fd958eee7cd266b9131c3d5c578fd116d9a`；它未部署，不能作为正式阈值。

等待用户仅用白纸遮住左边缘干扰、保留红圆并固定相机后，重测该候选的完整目标框、丢失和恢复。当前 JTAG 未枚举、FPGA UDP 未出帧，F1 与两摄像头关联仍未验证；KEY 原因、机械及波形标定也仍未解决。没有 ARM、真实 PWM、云台运动或光学控制；现场图片仅留 D 盘。
