## 审查重点

- bbox 两端包含，面积需要 +1，包围框面积不是掩膜 count。
- left/above 方向符合左上原点，二倍中心有符号差不溢出。
- 比较距离不需要 sqrt，比较 IoU 不需要浮点除法。
- unknown 与 false 不混同，丢失目标不保留当前有效坐标。
- 对象帧号/配置不一致不能生成有效关系。
- 同一对象对允许 left 与 above 同时成立，反向关系不能同时为真。
- 旧格式和 v1/v2 滤波语义无回归。
- 新增功能关闭时不改变现有相机/红色统计链路。
- 测试使用独立预期与固定随机种子，不改验收门槛来迎合实现。
