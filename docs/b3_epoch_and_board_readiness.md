# B3：epoch 与板级约束审查（2026-11-01）

本文件是离线审查，不是接线、供电、烧录或运动指令。基线为 B2
`078a7cf7b191fc27dc14f982781505aa291b3c64`。

## 1. epoch 的实际来源与重放证据

`zynq_motion_s1.v` 的 `epoch[127:0]` 是顶层输入。仓库没有生产级驱动端、
PS 启动流程或持久化分配器。B2/B3 testbench 使用固定夹具，只适用于仿真。
`last_epoch` 在逻辑复位时清零，只排除最近一次值；不是永久已用值集合。
人工查询复制 epoch，重新授权查询和 stop 在 qid 上递增。授权路径检查全1，
但取消/stop 的自增路径未统一检查回绕；内部使用的 QID 必须占用分配范围。
完全掉电和仅逻辑复位都可能重用外部提供的常量。

B3 将真实 C 生成的旧 S1SYNC 重放到复位后的 FPGA：同 epoch 时进入 AUTH，
不同 epoch 时保持 WAIT_SYNC。测试先发送换行以隔离残留半行；没有执行真实
运动，也没有声称不同仿真常量证明硬件唯一性。此结果证实外部接口契约必要，
并非发现了一个已经部署的随机数源。

**HARDWARE BLOCKER：跨复位 QID 新鲜性尚未实现和验证。**

## 2. 可实施的方案与风险（均为建议，未实现）

| 方案 | 必须证明的条件 | 剩余风险 |
| --- | --- | --- |
| 持久化分配器 + 分块预留 | 在释放任何 QID 前，双副本日志/事务提交不可回滚的高水位；绑定唯一设备命名空间；给 FPGA 整块、不重叠的 ID；内部递增不得越界 | PS 存储介质、断电原子性、克隆与备份回滚、寿命、维护恢复流程尚未知 |
| MCU 持久化启动代数 + 分块分配 | MCU 启动代数在供给客户端前耐掉电提交；运行中分配序号单调且不回绕；双方绑定新的挑战与确认 | 需要协议扩展、Flash 擦写寿命评估、掉电注入、重放链审查；不是简单接受一条 MCU 随机公告 |
| 合格硬件熵源 + nonce 去重策略 | 硬件健康测试、失败关闭、概率与使用次数上界、跨复位冲突应对 | 只能给碰撞概率，不能证明随机数绝不重复；目前无已验证的 FPGA 熵源 |

建议优先评审持久化区间分配，包含 namespace、block_start、block_end、耗尽后
故障、显式授权与复位作废。128 位输入不能直接用“启动计数器”填充；本地
寄存器会丢失，可靠性来自独立持久化事务和防回滚边界。禁止固定常量、普通
递增寄存器、仿真随机数或未经测量的时钟抖动进入实机版本。

当前 STM32 的 `board_session_nonce` 从 RNG 读取两个32位字，并检查时钟/种子
错误及非零、不相等；`safety.c` 在 stop/fault 时递增该64位 nonce。这既不是
128位 epoch 分配器，也不证明跨掉电绝对唯一。主机寄存器模型中的 RNG 是
确定性夹具，完全不能作为实物熵证据。参考 [ST RM0090](https://www.st.com/resource/en/reference_manual/rm0090-stm32f407-advanced-armbased-32bit-mcus-stmicroelectronics.pdf)
的 RNG/USART 章节；实际器件与熵源健康仍需独立核验。

## 4. 155/73 未约束端口的处理

B2 最终 timing.rpt 确实列出155个 no_input_delay、73个 no_output_delay。
OOC 中大量 epoch、目标、状态端口是抽象模块接口，不等于最终必须引出这么多
板上引脚。必须先选定顶层集成：PS/寄存器总线、内部状态/ILA、外部串口及人工
控制输入，再根据实际连接分类。不能给所有端口填0延迟或统一false_path来消除警告。

- 同域内部控制/状态总线：按真实接口时钟和握手约束，在完整顶层检查，而非
  伪装成外部IO延迟；多位 epoch/axis/pulse 要稳定保持并以握手原子采样。
- 异步人工输入：同步器、消抖、边沿限定；不得分别同步128位总线来假称一致。
- UART RX：已有两级 ASYNC_REG 接收同步；仍需检查布局、首级输入例外和MTBF。
  原始 pc_rx、pc_quiet_ack 在所有权判定中的跨域路径还需顶层审查。
- 异步复位：异步断言、每个域同步释放；证明恢复/撤销时间和上电稳定条件。
- 真实同步外部接口：用对端时序、板延迟与时钟关系设置 min/max IO delay。
  异步 UART 不存在可随意猜测的对端同步时钟；合理的CDC/边界分析不能代替
  物理电平和波形测量。
- 透传通路与时钟门控/所有权切换：需要实物 PC 静默协议和CDC证明；不同源
  不能半帧拼接。复位期间TX高，复位释放后PC路径依赖PC静默契约。

因此现有OOC正WNS不是板级收敛。新增XDC尚不具备可靠输入；本轮没有猜管脚或
覆盖原透传XDC。完整时钟、CDC、时序接口、J23电压、Flash身份、供电隔离和
外部PWM测量全部是进入受控实机申请前的门槛。
