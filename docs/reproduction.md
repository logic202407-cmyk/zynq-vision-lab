# 复现状态

## 现在能够复现的部分

仓库结构、Markdown 相对文件链接、状态文件和基础敏感文件检查，以及检查工具的单元测试。需要 Python 3.10+；不安装第三方依赖、不调用 FPGA 工具。

```bash
python tools/check_repository.py
python -m unittest discover -s tests -v
```

仓库检查会报告明显凭据格式与被禁止的文件类型，但不是完整安全审计，不能保证日志、图片中不存在个人信息。

## 尚不能复现的部分

摄像头采集、视觉算法、RTL/HLS、PS 应用、位流生成与板测尚未实现。没有提供占位“成功”的 FPGA 构建脚本。硬件与工具版本核验后再建立真实命令。

## 第一次板级复现所需材料

完整芯片 part、板卡与接口版本、工具/IP版本、实际时钟/复位约束、输入与黄金参考校验和、从干净目录重建的命令、实现后时序与资源报告、接线与启动说明、板测输出和失败边界。

另一名成员按指定提交重新构建并重复结果后，才标记独立复现。二进制成果可通过后续 Release 附件提供，并记录来源提交和校验和；不要只上传位流而遗漏源码与构建信息。
