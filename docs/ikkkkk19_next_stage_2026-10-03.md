复核已交付来源、私有依赖许可与哈希、GUI/命令行证据差异；有现成编译器时做非作者 host 复现，然后覆盖缺口、状态转移、全分片及系统 CRC 负控制。全为独立软件工作，不需要 FPGA、另一人回放、PC 适配器或团队协议。S02 依赖获取被阻塞时，保存已知事实，可继续已有合法依赖下的 host/源码审查；不擅自下载/安装或改 manifest。第一批不包括上板、串口、PWM、台架或光源。

PR7 已交付真实 C host 夹具、66 场景、3 队列回归、状态/解析/自动手动相关修复，作者 109 无 skip 和命令行构建证据。不再从零布置原 PID、历史、缓存或手动另一轴修复。新包聚焦未覆盖组合、数值性质、独立预期/复现与工程证据；一个既有场景向量不另算一个新工作包。

## 实际源码、依赖和当前语义

固定 [PR7](https://github.com/logic202407-cmyk/zynq-vision-lab/pull/7) head `04ba0db3e1a4f67cee7efa7b941d69ce281bffa2`，作者测试源码提交 `d42b658fa425d71838a604e7cbf42e8764b87129`。在本人干净分支读取 [BUILD](https://github.com/logic202407-cmyk/zynq-vision-lab/blob/04ba0db3e1a4f67cee7efa7b941d69ce281bffa2/src/prototype/stm32_openmv_gimbal/stm32/BUILD.md)、[PROTOCOL](https://github.com/logic202407-cmyk/zynq-vision-lab/blob/04ba0db3e1a4f67cee7efa7b941d69ce281bffa2/src/prototype/stm32_openmv_gimbal/stm32/PROTOCOL.md) 和相同提交的 User/tests。不要假定 PR4 或 main 包含它们。实际已有入口如下，只在用户选择执行且依赖满足时按 BUILD 操作；本轮不执行：

```powershell
python tools/build_stm32_p0.py --deps private/stm32-deps --tool-bin C:/Keil_v5/ARM/ARMCC/bin --output private/build-run-001
python -m unittest discover -s tests -p test_stm32_p0.py -v
```

使用新的输出目录，不覆盖旧证据。现成 host 编译器由 `P0_HOST_CC` 指定，新证据目录由 `STM32_P0_EVIDENCE` 指定。16 个 SPL3.5.0/CMSIS1.30 支持源仍需按 manifest 在私有目录合法提供；同版本不保证同字节，原始 zip/EULA 尚缺独立证明。ARM Compiler5.06 update5 build528 / MDKPlus5.24 的命令行 0 错误/0 警告不等于 uVision GUI 重建或实物通过；无合法完整依赖应记 blocked，不能把厂商源上传仓库。

临时 `stm32-p0/v1` 属于本人原型，不是团队冻结接口：26 字节 AA55/version1/len26、valid0/1、config1、uint32 非零 session，帧可从0开始但严格递增且 session/frame 不回绕，高 session 重置；source_ms 仅诊断。int16 dx[-80,80]/dy[-60,60]，invalid 强制零。CRC16 CCITT-FALSE（poly1021、initFFFF、不反射、xorout0）覆盖字节2–21，字段小端，尾0D0A。需继续按实际 PROTOCOL 精确核对，不擅自换成现有 RTL UDP 格式。

本地接收末字节 uint32 ms 定义时效，半帧20ms、失联/陈旧≥200ms，unsigned 时间差处理时钟回绕；源时钟不决定新鲜度。自动/增益屏障拒绝旧队列帧，invalid 清 PID/滤波历史且保留序号高水位。waiting/tracking/no_target/timeout/rejected 与 auto/manual 分开；invalid 停止自动更新并保留软件末脉宽，PWM 可能仍持续，不等于物理停止；PAN/TLT cache 不等于实测角度。72MHz、引脚、home/限位/滤波等只是原型编译参数，实物尚未核实。本任务不修改最终 PS/STM32 架构，不把 OpenMV 变成最终摄像头。
