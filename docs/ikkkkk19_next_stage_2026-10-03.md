## 当前 P0：自己完成实现与软件验证

1. **补完整可重建工程。** 核清并提交必要原创源/头文件、工程配置和实际工具/依赖版本；第三方依赖记录官方获取路径、版本、授权及人工获取步骤，不复制未获再分发授权的文件。说明 OLED/delay 是否必需。用干净克隆实际构建，保存命令、完整日志、退出码、错误/警告和产物 hash；旧本机 Keil 成功不能代替。
2. **建立自己的模拟输入/夹具。** 用本地 host/mock、单元测试或自有测试夹具逐条输入，并自行保存独立 expected。格式/封包/校验/时钟/超时/恢复及 session/帧规则注明为“独立临时版本”，记录具体版本和值，**不是团队冻结协议**。无需等 `3331083641-prog` 提供回放，也不开发双方联调适配。新测试接口未实现前先列待开发，不能假装已有命令。
3. **修 PID/滤波陈旧状态。** 旧 [main.c](https://github.com/logic202407-cmyk/zynq-vision-lab/blob/d96bc149bc25f0572350c47ed031c0922ec265ad/src/prototype/stm32_openmv_gimbal/stm32/User/main.c) 的 `FRAME_TIMEOUT_MS=200` 路径只让 DX/DY 上报零，未在该路径清 PID/滤波历史。使有效零误差、无目标、断流与恢复可区分；失效不再使用旧测量，按自己的临时策略处理 PID 积分/历史、滤波、跳变和缓存状态，恢复记录初始化/使能条件。报零不等于停止；200ms 只是已有参数，不是最终标定门槛。
4. **修单轴缓存与解析。** 单轴手动命令不应意外改另一轴；同步 `pan`/`tlt` 缓存、主循环实际应用值与上报。覆盖交替单轴、自动/手动转换和未变化轴保持。补 parser 后拒绝坏长度/校验/版本/有效位/越界/缺字段并验证重同步；session 切换、重复/乱序/断流恢复按本人的临时契约测试和留证。不能称旧 8 字节原型已支持团队新契约。
5. **真实跑下表并留结果。** 先软件/模拟层记录解析、状态、拟输出、应用值和拒绝原因；尚未实现或工具不可用的项记 `not_run`。自有夹具若接实际 STM32/串口，仍需另行确认具体设备、端口、独占和当次许可，不自动打开未知端口或启动执行器。

| 独立测试输入 | 必须观察的预期边界 |
|---|---|
| 有效目标、非零误差 | 本次有效测量进入正确状态，模拟轴符号和应用值可对照 |
| 有效目标、零误差 | 保持有效观测；不能误标 lost，也不能与停止状态混为一谈 |
| 无目标/无效或缺测 | 不复用旧坐标，明确原因和本地停止/禁用策略 |
| 断流后正常输入恢复 | 超时与恢复状态可区分，PID/滤波/缓存按临时策略处理，不悄悄继承旧输入 |
| 畸形数据后正常数据 | 保存拒绝原因、重同步和恢复，不以坏数据产生有效拟输出 |
| session/帧/配置边界 | 旧会话、重复/乱序/合法新会话等按明确临时规则判定，不能把 source 时间当接收时间 |
| 单轴/模式切换 | 未变轴保持；缓存、实际应用值和上报一致，输出不被旧自动状态覆盖 |

P0 完成需要干净工程真实可重建，上述已有实现的检查确实运行并有输入/独立预期/实际日志；缺项和失败不隐藏。模拟拟输出证明软件状态，不证明 PWM、限位、物理停止或云台运动。

最终相机是现有固定 OV5640→FPGA/Zynq、镜头不随云台转；旧 Tilt 相机随轴转解释、轴反号与 PID 参数不能照搬。当前只模拟并标明待重新标定项，不换摄像头、不实施最终实物视觉闭环；PS/STM32 最终架构未决定。
