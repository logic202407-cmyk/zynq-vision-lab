# 首周任务与验收

日期：2026-09-18。所有硬件与算法任务初始状态均为“未验证”。这是开发任务计划，不是已完成的硬件成果。仓库目前只提供文档、目录与基础检查工具。

## t00 报名与范围确认

负责人：队长；复核：指导教师。

输入：现有团队意向、赛事公告、学校通知。  
输出：`private/registration_check.md`（仅本地保存，不提交） 与 `report/scope.md`。

动作：确认实际参赛三人及顺序、组别、指导教师、报名系统状态和校内截止日；记录“几何靶标、真实 PL 处理、动态干扰测评”的一期范围。

验收：报名页/确认信息已人工核对，未公开敏感个人资料；scope 明确必交付、可选功能、未纳入范围。没有完成报名不能在周报中写“已报名”。

## t01 硬件身份与资产盘点

负责人：队长；复核：实验负责人。

输入：实际板卡、附件、购买/原厂资料。  
输出：`board/hardware_inventory.md`、`board/photos/`（只放经脱敏、获准公开的照片）。

动作：拍板卡正反面与芯片标记，记录原厂工程器件 part；确认相机模块型号、接口和原厂适配资料；列明显示器、存储卡、下载器、电源、线缆是否真实可用。

验收：每件资产使用“在手已测试 / 在手未测试 / 不在手 / 待确认”四选一。芯片型号与原厂工程不一致时不得继续猜引脚。库存以实物核验为准。

## t02 最小工程重建与上板

负责人：队长；复核：第二名成员。

输入：与实际板卡匹配的原厂最小工程及工具版本。  
输出：`build/toolchain_manifest.md`、`board/bringup_log.md`、原始构建日志。

动作：记录操作系统、Vivado/Vitis、IP版本和许可状态；使用匹配的最小例程完成综合、实现、位流生成和下载；观察例程应有的可见输出；第二次从干净工作目录重建。

验收：保存实际成功/失败日志，位流的器件目标正确，两次构建与运行结果有记录。安装成功、软件能启动、工程能打开均不等于完成此任务。

## t03 第一版数据契约

负责人：软件参考负责人；复核：队长。

输入：已核实的视频输入格式与一期范围。  
输出：`src/interface_contract.md`。

至少定义：分辨率、像素格式/通道顺序、坐标原点、帧编号、有效/无效状态含义、统计结果更新时机、软件何时可以读取完整快照、计时开始/结束边界。

验收：软件参考与硬件负责人对同一张测试图的坐标和像素解释一致。未知接口明确列为“尚未确定”，不能用默认值悄悄代替。

## t04 软件黄金参考与小型测试集

负责人：软件参考负责人；复核：实验负责人。

输入：数据契约及自采/自制几何标靶图像。  
输出：`sim/reference/`、`data/test_manifest.md`、`data/reference_results/`。

先建立六类输入：无目标、单目标居中、目标靠边、多个可区分目标、相似背景、部分遮挡。第一版参考用于确定像素处理与输出定义，不要求部署机器学习模型。

验收：每个输入有来源、预期行为、参考输出；参考程序自身先测试空输入、尺寸不符、无前景和边界等行为；实际测试命令与输出有记录。尚未编写程序时，只标记“任务已规划”。

## t05 原厂视频基线

负责人：队长；复核：实验负责人。

输入：板卡匹配的原厂摄像头/显示工程。  
输出：`board/video_baseline.md`、短视频、帧到达统计或其他可取得的原始证据。

动作：先原样跑通并记录版本，再考虑插入自编处理。确认显示是否实际来自当前摄像头，而不是测试图或录像；确认自动曝光等设置能否查询/固定。

验收：至少连续 5 分钟可见正确来源的画面，原厂链路可按文档重复启动。若接口尚不支持帧率测量，则显示“未测”而非额定值。

## t06 首个自编 PL 模块的测试设计

负责人：队长；复核：软件参考负责人。

输入：数据契约、黄金参考、基础视频链路。  
输出：`src/rtl/` 或 `src/hls/` 中一个职责单一的模块、`sim/` 内对应测试，以及模块接口说明。

动作：只选一个基础像素算子或统计模块；先写能识别错误的测试，再写实现。测试覆盖复位、有效数据间隔、边界及空场景。不要首个模块就做通用多目标识别。

验收：仿真实际输出与黄金参考比较；记录故意引入可控错误时测试是否能失败。第一周来不及上板可据实停在仿真状态，不宣称整个系统完成。

## 首周评审只看四件事

1. 报名是否已实际完成，板卡和工具链是否清楚。
2. 是否存在可以重建并下载的工程，而不是只有截图或视频教程。
3. 是否有一致的数据格式、参考输入和预期结果。
4. 下一周的主要阻塞是视频接口、工具环境还是自编算法，是否有明确责任人和证据。

优先关闭一个阻塞，不同时开启 PYNQ 移植、神经网络、移动底盘和多路光学机构。
