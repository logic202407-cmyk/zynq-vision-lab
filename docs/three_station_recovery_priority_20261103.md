# 三套视觉装置：当前缺口与限时推进顺序

更新时间：2026-11-03 20:10左右。以无生命几何纸靶和只观测数据为当前范围；
舵机及激光动力仍物理断开。用户已授权仅复位STM32一次，尚待现场执行结果。
本页不是三套运动或光学命中验收。

## 已确认的实物进展

- 同一只观测BIT在电脑2本地易失配置成功，立即/30秒DONE和EOS均1。
- 配套LTX与实际1个VIO核匹配；电脑1可读写仅查询/STOP的观测控制。
- 300秒视频组装7884完整帧，0不完整帧，1异常数据报；未据此证明画质。
- 真实S1SYNC查询及STOP应答的CRC和关联通过，PWM mask0。
- MCU当前fault parse锁存，未绑定会话，F1仍0。原因尚未独立定位。

## 限时推进策略

1. 单套现场链路：一次授权STM32复位，持续保存启动及30秒状态。若parse重现，
   停止重复复位，定位控制台输入/故障时序。若稳定stopped，用新query和有效
   session完成绑定，检查F1；不借助ARM清故障。
2. 与现场故障独立准备：从OV5640真实画面建立三个纸靶的检测/ID与观察端
   分配可视化。先确认靶标是否允许颜色/编号区分；固定区域方案只适用于固定
   场景，不能冒充任意移动目标跟踪。PC候选结果标记PC_REFERENCE，不塞进PL
   测量槽冒充FPGA计算，不为此重刷已恢复位流。
3. 硬件拓扑马上冻结：每套独立STM32，或单STM32管理三套，或后两套尚未接线。
   这三种情况资源/固件工作量不同；未确认前不猜UART/PWM引脚。
4. 第一套接口通过后逐套复制已经验证的数据协议和测试，而非同时接上所有
   硬件后查混合故障。每套先证明自己的身份、数据和断连行为，再做三套同时观测。
5. 光学演示条件单独核实：仅纸靶、光源等级/功率、场地及可达区域。当前
   激光保持断电；屏幕上的目标分配成功不等于激光命中或机械标定通过。

时间管理：每个现场阻塞限定一次可解释的对照试验，产出日志后转向独立可做
工作；不连续重下载、不反复改网络、不重复已经通过的全仓库测试。
本页时间顺序是工作优先级，不是未验证工期承诺。
